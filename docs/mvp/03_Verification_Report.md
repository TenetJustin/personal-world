# MVP 实际验证报告

2026-10-25 · 本轮用户故事：用户从资料应用添加真实文件 / 正文 → IndexedDB 原子持久化 → 阅读 / 刷新 → 完整备份 → 空库恢复 → 在同一资料桌面继续使用；3D 为可绕过的可逆入口。

## 环境与执行范围

MacBook Air Mac17,3，Apple M5（10 核 CPU / 10 核 GPU），24 GB 内存；macOS 27.0.1 (26A434)。Codex 内置 Chromium 155，UA 内的 Intel / macOS 10.15 字样不是真实硬件。桌面截图 / 3D 绘制缓冲 1280×720，标准质量 DPR 1；实际屏幕 DPR 2。使用本机回环地址，未模拟公网网络。端口 5178 / 5179 为隔离测试库，5177 为正式使用地址。

**素材均为标明测试用途的原创验收资料，不是真实个人档案。** 核心功能通过不代表照片级美术通过。

## 加载与性能

资料直达页本地测量：DOMContentLoaded 38.7 ms，load 42.8 ms，两个 JS / CSS 资源 encodedBodySize 共 78,137 bytes，transferSize 共 78,737 bytes（不含 HTML）。本地服务压缩与缓存环境不代表真实公网加载。原始记录 `content-load-diagnostics.json`。

标准档湖岸固定 A：预热 2 秒，实际采样 15.013 秒 / 540 帧。平均 **35.97 FPS**，p95 **31.90 ms**；最多 352 Draw Calls / 18,670,585 三角形，包含主渲染及实际反射 / 透射等附加 pass。可见性排除 0，错误为空。绘制缓冲 1280×720 / 标准档，不可与此前 1440×900 / 高档 B 的数据直接做提升比例比较。原始逐帧记录 `exterior-performance.json`。

该页从导航后先操作了资料和 PDF，再进入 3D，所以原始 navigationToFirstFrameMs / assetPreparationMs 包含用户停留时间，**不当成纯 3D 下载耗时**。本轮已补充“进入 3D”起点与 entryToFirstFrameMs，后续诊断可区分两者。进入前后资产 encoded 累计约 35.38 MB，其中含本次 PDF 与 3D 可选资源；完整发布目录另含可选高档 HDR / blockout，不能把总目录体积当首次下载量。

桌面暂停 WebGL；不把暂停后的显示称为 60 FPS。3D 当前平均帧率仍低于原目标 50–60 FPS，是后续优化项；按用户已调整范围，不阻挡资料 MVP。

## 本轮修复与保留问题

- 修复原生 PDF 预览空白，加入本地 worker 的分页阅读及辅助文字；PDF 文件不发送到外部服务。
- 修复 PDF 在列表中被当作图片缩略图的问题。
- 新建资料直接进入编辑；草稿切换应用仍保留，刷新前提醒未保存。
- 场景 readiness 使用明确就绪事件；相机初始配置保持稳定。
- 备份完整验证后事务写入，坏文件不会先写一部分；删除采用可恢复回收站。
- 原 Phase 01B 草地、森林、石材、木纹、反射与山景问题保留。室内是简化代理；门口和电脑切换为短淡入，尚非连续精细相机动画或像素级 ScreenBridge。
- 物理 iPhone / Android、Safari / Firefox、WebGL 丢失恢复故障注入、配额耗尽、5,000 项压力、加密 / 复杂多页 PDF、30 分钟资源压力与 20 次往返矩阵：NOT_RUN。本机常规流程证据不能替代这些测试。

## 结论

建议交付本地资料 MVP 并开始放入真实个人资料；每次整理后保留外部备份。保持 Private、开发分支、不合并 main、不公开部署。后续先处理用户真实使用中出现的数据 / 可用性问题，再逐步精修视觉。没有宣称原照片级门槛或全部 Phase 原始验收矩阵已通过。

## 最终运行包补充验证

最终构建通过不依赖 npm 模块的本机 Node 静态服务器运行，资料深链接刷新和室内→书桌→桌面通过。进入 3D 到首个实际帧 1460.8 ms，场景准备 769.5 ms（本地资产缓存未主动清空；不是公网冷启动成绩）。桌面连续 37.5 秒，两次实际渲染总帧计数均为 3599，确认保留 Canvas 同时暂停渲染，见 desktop-pause-check.json。

完整运行资产（含可选高档 HDR、blockout 和本地 PDF 资源）70,460,026 bytes；首次 Notes 入口只加载前述约 78 KB 的 JS / CSS。正式地址的临时验收笔记已移入回收站；未删除用户资料。主要多应用导入 / 恢复测试位于独立端口，不作为虚构的个人档案预置。
