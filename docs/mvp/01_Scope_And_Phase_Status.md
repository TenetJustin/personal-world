资料路由 `/notes/`、`/photos/`、`/projects/`、`/resume/` 为本地 SPA 路由，支持 Vite 服务刷新与浏览器前进后退。内容只存在当前浏览器，因此没有对外生成可被搜索引擎索引的私人正文。

## 数据与约束

- IndexedDB 数据库 `personal-world-library`，schema v1，原文件 Blob 与正文一同持久化。
- 备份格式 `personal-world-backup` v1：JSON + base64 附件，包含四个应用及回收站。合并恢复，相同 ID 以备份版本替换，不删除其他记录；写入前完整验证，事务提交。
- 单个附件 25 MiB、正文 1,000,000 字符、总库约 100 MiB / 5,000 项，备份输入 150 MiB。为 MVP 的可控本地容量边界，浏览器自身可用配额可能更低。
- 照片 JPEG / PNG / WebP / GIF；保留原文件。PDF 采用本地 PDF.js 阅读与分页；无外部文档服务。
- 基础 Markdown：标题、无序列表、代码块、引用、粗体、行内代码和安全 HTTP(S) 链接。原始 HTML 只显示文字；不声称完整 CommonMark / GFM。
- 删除仅移入回收站，可恢复；不提供不可逆清空按钮。
- 草稿在应用切换、最小化和返回木屋时保留在 React 内存中。必须点击保存才能持久化；刷新有未保存提醒，浏览器崩溃不保证草稿可恢复。
- 没有上传接口、遥测、远程字体或账户服务。库没有额外密码或静态加密层，访问本机该浏览器的人可以使用资料库。
- 地址与端口是数据身份的一部分。固定使用 `http://127.0.0.1:5177`；换地址 / 浏览器时用备份迁移。
