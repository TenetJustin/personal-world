## 需要真人确认

1. **原生离页警告**
   - CDP 已捕获 Chrome `beforeunload` 事件（`hasBrowserHandler: true`）。
   - 自动流程没有点击原生对话框按钮；请用正常 Chrome：输入资料 → 切到其他应用/点关闭 → 刷新，确认浏览器弹出“离开此网站？”并选择“取消”后内容仍在。
2. **原生切后台暂停**
   - 代码在 `visibilitychange` 时调用 `AudioContext.suspend()`；合成事件与引擎 suspend/resume 已验证。
   - 自动化窗口即使最小化/多标签仍报告 `visible`，无法触发真实原生隐藏；请在正常 Chrome 切换标签，确认声音暂停、返回后恢复。
3. **Pointer Lock**
   - 自动化窗口可能被浏览器拒绝；拖动观察已验证。请真人点击“锁定鼠标观察”确认锁定与 Esc 释放。
4. **真实手机**
   - 390×844 为桌面浏览器移动视口 + 触摸模拟；请在实体手机上检查摇杆、右侧拖动、发热与帧率。

## 已知产品限制

- 室外森林、草地、岩石仍是 V2 视觉水平，未达到照片级。
- macOS 桌面未与用户真实桌面逐像素对照，不声称 95% 相似度。
- 天气仍是明确 DEMO 占位，不读取定位、不编造实时数据。
- 环境音是原创合成，不是现场录音；没有音乐或第三方样本。
- 完整路线运动平均约 50 FPS；桌面固定镜头 60 FPS。若要求全程稳定 60，需要继续优化水面反射与远景林分。

- Source GLB/Blend 仅作可编辑资产，不参与运行时加载。
