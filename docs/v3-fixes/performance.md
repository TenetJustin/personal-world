# 性能实测（v3-reliability-audio）

2026-10-26。真实有头 Chrome + Apple Metal GPU；不是离线渲染，也不是估算。

## 条件

| 项 | 值 |
| --- | --- |
| 机器 | MacBook Air，Apple M5，10 核 GPU，24 GB |
| 系统 | macOS 27.0.1 |
| 浏览器 | Google Chrome 155 |
| 视口 / DPR | 1440 × 900 / 1 |
| 质量 | 默认 standard（阴影 2048、反射 512、无 `quality=high`） |
| 构建 | 生产构建，`/personal-world/` 子路径，本地回环 |
| 方法 | 每个固定镜头 2 s 预热 + 10 s 采集；`gl.info` 每帧重置后统计 draw calls |
| 原始数据 | `outputs/v3-fixes/performance-verified.json`、`performance-tour-verified.json` |

固定镜头来自 SceneQA 的明确验收定位，不是实际行走；完整引导是实际运动。

## 结果

| 镜头 | 平均 FPS | p50 | p95 | p99 | Draw calls | Triangles |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 一层客厅/厨房固定镜头 | **60.0** | 16.7 | **18.3** | 18.7 | 241 | 11.06 M |
| 二层固定镜头 | **60.0** | 16.7 | **18.0** | 18.5 | 260 | 11.39 M |
| Mac 键盘特写 | **60.0** | 16.7 | **17.4** | 18.4 | 251 | 11.17 M |
| 湖岸固定检查镜头 | **60.0** | 16.7 | **17.9** | 18.4 | 385 | 14.83 M |
| 完整自动引导（运动） | **50.1** | 18.8 | **26.3** | 29.3 | 492 | 19.71 M |

完整引导：5 秒等待 + 路线，37.9 s 到达 `DESK_READY`；采样 1886 帧，
p95 26.3 ms < 33 ms。采集期间为了保存阶段截图有额外开销，因此该平均值是
偏保守的实际运动数据。

## 与历史 44 FPS 的关系

上一轮曾记录湖岸约 44 FPS。那一轮与本轮不是同一构建、同一镜头、同一采样
条件（当时包含不同的水面反射策略与测量流程）。本轮湖岸固定镜头为 60 FPS，
**不能**据此宣称“同条件提速 36%”。可确认的是：当前构建在本机 1440×900
标准质量下，四个固定镜头均达到 60 FPS 且 p95 < 19 ms。

## 解释

- 室内固定镜头 241–260 draw calls，低于 V2 桌前的 329；室内 GLB 合批有效。
- 湖岸固定镜头仍更高（385 calls / 14.8 M triangles），主要来自森林、草地与
  水面反射；`Water.js` 在静止镜头复用全分辨率反射、约 20 Hz 更新，
  相机/投影/阴影变化立即重绘；`?liveReflections` 可关闭缓存。
- 实际运动平均 50 FPS，主要成本是水面反射二次绘制与远景森林几何；
  p95 仍低于 33 ms。
- 没有通过隐藏森林、降低 DPR 或缩短草本来提高数字。

## 未验证

- Safari / Firefox / Windows / 真实手机 GPU。
- 公网冷缓存首屏（本报告是本地回环）。
- 录制工具运行时的帧率不能替代本报告；录屏只作视觉证据。
