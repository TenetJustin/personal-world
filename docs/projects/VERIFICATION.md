## 真实浏览器与备份

Chrome 155.0.8059.85，桌面 1440×960，模拟手机 390×844。本轮没有声称实体手机或各显卡性能通过。

真实 UI 检查了五个项目、搜索、每张普通画廊图加载、放大与左右切换、Escape / 焦点恢复、深链接刷新、MOIRAI 悬停／焦点暂停、Reduced Motion、触摸事件横滑（352 px）。页面异常与失败请求均为 0。

本地开发服务用两个独立空白浏览器上下文完成：复制五组公开项目到 IndexedDB → 修改 MOIRAI 副标题、周期与图片说明 → 保存 → 下载真实 v2 备份（14 张图与缩略图均嵌入字节）→ 在另一个上下文恢复，核对元数据与图片。测试值没有发布，未读取用户日常浏览器资料。

## 实际录屏发现与修复

第一轮连续录屏回看发现最后一张牌因变换动画中的浏览器懒加载而留空，原来只检查开始／结束画面的技术测试没有捕获全过程缺陷。本轮未把该版本部署。

修复为：牌廊挂载后预载所选图片，全部解码完成后再启用滚动；普通项目截图继续惰性加载，整套项目图不会进入湖岸首屏。强化浏览器验收，先确认主队列 12 张牌全部成功加载，再录制完整周期。

最终单独录制覆盖 44.1 秒实际动画时间，超过完整 36 秒周期，1440×1100 视口中整张牌完整入镜，未加速；原始 WebM 与移除片头 3 秒准备画面的同速 MP4、抽帧联系表保存于本机交付目录。最终画面审美与动作节奏可继续由作者播放原始视频判断，不以自动化代替人工视觉意见。
