## 剩余视觉缺陷 / 人工检查重点

1. **草地仍有重复和成簇感**，局部过暗、块状，欠缺不同物种、幼草、湿泥、落叶、根系之间连续而细腻的过渡。应在主镜头可见带继续手工布置，不以数量或绿色替代自然细节。
2. **树冠叶簇仍可能呈片状或噪点**；中远景图集与近景实时 PBR 的亮度 / 阴影尚非完全一致。当前只有一种主要针叶轮廓，森林生态丰富性不足，部分树下缺少接触暗部。
3. **石材仍偏规则砌块**，烟囱和基础应进一步增加真实石种、边缘损耗、细微接缝和尺度变化。当前扫描 PBR + 不规则体块优于纯色，但不能等同高质量逐石雕刻。
4. **原木反射与端纹仍需精修**：色调、粗糙度和缝隙较均匀，部分侧光仍显计算机图形质感；尚未做完整太阳间接反弹 / 局部接触烘焙。
5. **玻璃仍主要使用全局环境与屏幕空间透射**，没有每扇窗专用的局部森林反射探针；深檐下窗口可读性与真实玻璃的复杂反射仍有差距。
6. **远山主体仍受 CC0 HDR 照片内容和分辨率限制**。新增山麓有视差，但不具备精细侵蚀 / 地质层次，背景中的非北欧地貌细节也尚未完全消除。
7. **水体是实时 planar reflection 与近岸吸收近似**，不是完整物理折射 / 水下散射；近岸细节与复杂地形仍需逐像素人工检查。
8. **房屋生活痕迹较少**：仅有门廊长凳、五金和灯具，尚无自然磨损、雨水痕迹等精细叙事。不要为增加道具越界开发室内或无关功能。
