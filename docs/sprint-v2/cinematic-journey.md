# 第一人称长镜头与空间交互

2026-10-26。功能 MVP 已贯通，摄影与照片级视觉效果仍须用户人工验收。

默认眼高为所在真实完成面上 1.65m，PerspectiveCamera FOV 52°。路径依次贴合地形、五级台阶、门廊、门槛与室内地板；固定路径限制移动，拖动/方向键允许环视，不使用轨道相机。建筑与家具坐标由 `architecture.ts` 统一定义，`journey.ts` 是唯一运动状态机，Exterior Stage 是唯一相机写入者。

## 三个观察瞬间

- **湖岸**：资源可交互后等待五秒。自动引导开始先静观湖面与远山 3.4s，再用 4.8s 转向木屋；随后沿岸步行，不从第一帧直冲住宅。
- **门廊**：户外约 1.28m/s，台阶降至约 .46m/s；门前观察，停留 3.2s 等实际铰链门叶打开 100°。镜头穿过真实开口后进入同一世界的室内。门框、门叶与光照形成空间过渡，没有剪切或穿过固定门板。
- **书桌**：入室后观察环境与面湖窗户 6.2s，再用 3.2s 转向 Mac，最终以约 .76m/s 接近并缓停。81.75s 路线终点为 DESK_READY，须主动点击实体电脑或可访问按钮，才靠近屏幕并进入 DOM。

速度使用缓起缓停，视线使用四元数最短路径插值。当前不加入步行摇头，以避免夸张晃动；这仍需人工舒适性测试。入室曝光从1平滑到1.07，不以 Bloom 或景深掩盖材质。

## 接管、恢复与减少动态

真实有效指针位移（6px阈值）、拖动、滚轮、点击和按键取消自动资格；后台、加载、错误、桌面或帮助面板阻止自动计时。自动引导仅一次，中断保存当前位置/朝向，继续从当前进度起步。返回湖岸走同一安全通道；椅子不占走廊。Reduced Motion 禁止完整自动步行，提供简短安全定位和直接资料入口。

一个 Canvas 在进入桌面时保留尺寸并暂停。Mac 屏幕真实四角投影产生 CSS 单应矩阵，先对齐统一屏幕预览，再展开真实 React 桌面。退出反向收回并恢复原桌前位置、朝向及资料状态。实际浏览器测得四角最大误差约 .0272px；此指标只证明几何对齐，不证明过渡美感。

## 录制说明

`outputs/sprint-v2/webgl-continuous.webm` 是实际浏览器 Canvas captureStream/MediaRecorder 连续录制100秒（编码98.54秒、2918帧、约29.61fps）的原始录制，包含五秒等待、三个观察瞬间与抵达等待；没有离线渲染、补帧或生成图。MP4为便于播放的转码。

`first-person-browser.mp4` 是真实完整浏览器视口采集，涵盖主动点击 Mac、DOM 资料阅读和退出。采集968张画面，保留真实时间间隔；中位采样约10.2fps，工具调用间有停帧，最大19.31s间隔出现在操作/桌面阶段。不是原生30fps整页录屏，因此不以此单独判定微小闪烁或流畅度。连续画布录制补充完整步行过程。原生标签页捕获授权因无法确认选定目标被自动审批拒绝，未捕获其他应用或整个屏幕。
