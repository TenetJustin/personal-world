# Sprint V2：可通行建筑与书桌坐标契约

2026-10-25。此项解决真实门洞、开合门叶、室内尺度和笔记本屏幕投影的数据一致性。原始 Phase 01B 外立面、屋顶、烟囱、门廊及世界摆放保持一致；不宣称照片级视觉验收通过。

## 模型与许可

- 历史母版 `assets/architecture/cabin-phase01b.blend` 保持原样。
- 新母版 `assets/architecture/cabin-sprint-v2.blend` 保留原建筑全部可编辑对象，增加独立左铰链门组。
- `public/assets/cabin.glb` 为原外壳移除门叶后的 Meshopt/WebP 优化版本；真实门洞并未用隐藏墙体模拟。
- `public/assets/cabin-door.glb` 是围绕物理铰链原点导出的单独门叶，包含七块木板、两条铁铰和把手。母版仍逐件可编辑，运行时合并成两种材质的网格。
- 建筑、室内家具、笔记本造型、地板木纹与键盘贴图均为项目原创。门叶复用既有 Poly Haven `rough_wood` CC0 木材贴图，外壳仍使用已登记木材与石材资源。没有电影图片、商标、未授权模型或私人内容进入运行资产。
- 运行屏幕使用 `screenPreview.ts` 的原创统一桌面预览；不是将资料阅读器永久绘入纹理。

## 统一空间

全部长度为米、Y 向上。`src/scene/architecture.ts` 是导航、家具和屏幕投影唯一坐标契约。局部 +Z 面向湖泊，建筑世界原点 `[8,0,-3]`，绕 Y 轴 -35°。

门洞中心局部 X=1.11、Z=4.5；门框内净宽 X=.555–1.665，门楣下缘 Y=3.67。铰链 `[.55,1.35,4.5]`，向内开启 100°。门叶底 Y=1.38，清除完成面 Y=1.37；两侧保留毫米级间隙。入口阈值实木条桥接原结构地板与门廊，门廊 Y=1.3525。

五级入口踏步中心 Z=7.03/7.33/7.63/7.93/8.23，踏步顶面 Y=1.335/1.165/.995/.825/.655；最上一级与门廊相交部分由较高的真实门廊面优先。每级深 .315、净宽 1.92；外围地形高度不参与替代这些真实表面。

第一层室内安全边界 X±5.82、Z±4.32。书桌宽 1.90、深 .85，高 .76（顶面 Y=2.13），局部中心 X=-3.6、Z=2.95。椅子停在左侧，不占从门到桌前的导航走廊。其他家具在后方或侧墙附近；碰撞盒在共享契约中登记。

笔记本约 14 英寸、基座 .38×.255m。屏幕真实显示矩形 .348×.2295m，面朝局部 -Z，上缘向窗户后倾。其四角按访客所见左上、右上、右下、左下导出局部与世界坐标，屏幕法线、纹理 UV 与 DOM 投影保持一致。桌前眼位 `[-3.6,3.02,1.1]`，对应地板1.37+眼高1.65。窗口与湖景来自同一室外世界。

`buildWorld()` 返回 `updateDoor(openness)`，输入0–1，按相同铰链与角度驱动实际独立门叶；改变时使缓存的太阳阴影失效，避免关门阴影残留。V2 不再通过 `?blockout` 切换带固定关门的历史灰模；灰模文件仍保留作 Phase 01B 档案。

## 复现与验证

1. Blender 5.2.2 后台执行 `scripts/build_cabin_sprint_v2.py`。
2. `node scripts/prepare_cabin_sprint_v2.mjs`。
3. Blender 后台执行 `scripts/verify_cabin_sprint_v2.py`。
4. `node scripts/write_phase01b_manifest.mjs`。
5. `node --test tests/architecture.test.ts tests/asset-manifest.test.ts`。

Blender 几何检测对门洞9条不同横向位置/身体高度射线分别验证：外壳通畅、关门阻断、100°开门后通畅，记录在 `architecture-validation.json`。压缩后的门叶铰链局部包围盒另外检查为 X=.0094–1.1106、Y=.0300–2.2900、Z=-.0499–.1350，世界高度因此为1.38–3.64，与地板和门楣保持真实净空。单元测试检查可逆坐标变换、实际楼板/门廊/踏步高度、桌前不落入家具以及屏幕角点方向。

上述是几何和数据一致性检查，不代替真实浏览器连续镜头录屏、门口穿行观察与人工视觉验收。室内目前为可用简化布置；家具材质精修、逐光源烘焙、当地反射探针、室内装饰与更丰富生活细节继续列为 Phase 05 待办。
