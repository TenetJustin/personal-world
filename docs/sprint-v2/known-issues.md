# 已知问题与 Phase 05 建议

2026-10-26。当前交付目标是可用 MVP，不宣布照片级或电影摄影人工验收通过。

## 已解决

真实门洞和独立开合门叶、统一建筑尺度、第一人称安全通路、三个观察瞬间、五秒仅一次自动引导、接管与续行、Mac 四角投影与 DOM 展开、单 Canvas 返回、四应用分类/相册/项目图片/结构化履历、本地备份迁移、显式审核静态发布、Pages 子路径与直接路由。

## 剩余限制

- 环境仍有重复草卡、稀疏/规律树冠、平坦地面、山体 HDR 细节不足及缺少多层实体远景；不满足照片级自然环境目标。
- 室内家具为原创简化模型，圆木纹理/高光重复，室内间接光、玻璃反射、家具接地和门廊局部阴影需精修。没有完整二层生活空间与室内装饰。
- 导航是安全路径上的半自由观察，不是完整自由行走。门外回走与绕行视线仍可进一步摄影打磨。未使用幅度明显的摇头。
- 100秒连续 WebGL 实录不包含 DOM；完整 UI 实录为时间戳画面采集，有采样和工具间隔限制。需用户另行进行原生高帧率整页录屏验收。
- 本地原始响应约39 MiB，Pages本次资源编码体积约32.3 MiB（未清空缓存），模型、HDR仍偏重。当前运行 GLB 使用 Meshopt / WebP，未完成 KTX2/流式地形/设备自适应质量；低端手机3D性能未测。
- 公开附件当前一次加载，公开照片增多后应改按详情加载、响应式尺寸、延迟 PDF。四应用功能优先，不含复杂多窗口桌面、全文索引、云同步或账户。
- 原图导入默认保留可能包含 EXIF；需要公开时必须人工检查。可明确选压缩 WebP去除EXIF，但它会丢弃原文件与 GIF 动画，应先备份。
- 浏览器草稿绑定来源；localhost、Pages、不同端口/浏览器及自定义域名不能自动共享。下载完整备份后再迁移。清除网站数据会删除未备份草稿。
- 公开源码与内容在 Git 历史中可见；取消当前发布不能撤回他人下载或历史副本。没有把用户真实私人资料当作测试内容。
- 只在当前 Mac 的 Chromium 与手机尺寸模拟验证；实体 iPhone/Android、Safari、Windows、低端GPU、弱网冷缓存仍待实测。

## Phase 05 顺序

1. 用户确认三个观察瞬间、步速、门口停顿、Mac使用距离；完成舒适性与实体手机测试。
2. 保持导航锚点和屏幕契约，替换高精度家具/木材/石材，制作局部反射与间接光，改善门窗玻璃。
3. 重建近景岸线、草地密度/物种变化/接地，优化森林群落、实体远山与光照一致性。
4. 以画质对照和真实设备数据推动 KTX2、层级资产、可视区加载与质量分级，不用性能数字替代视觉审查。
5. 真实资料审核后发布，优先按需加载公开附件，完善小批量内容更新、撤销和版本预览。
