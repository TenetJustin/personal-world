# V3 个人资料填写中心

2026-10-26。与既有 Notes、Photos、Projects、Resume 共用同一 IndexedDB `personal-world-library` v1 与 `entries` store；没有第二套数据库、前端口令或管理员认证假象。

## 访问与角色区分

普通访客默认只读作者已发布内容，即使当前浏览器曾保存草稿也不会自动将它冒充公开资料。点击明确的“本地编辑工作区”进入当前浏览器的编辑状态，再打开“个人资料填写中心”。该入口不授予服务器权限，不能直接修改作者网站。GitHub Pages 没有访客写入 API。

中心提供五个可随时返回的栏目，以及 Projects / Photos / Notes 的现有应用入口。每个栏目显示已填写数量、核心信息缺失提示、保存状态与实时预览。可以分次保存未完成草稿，不必填写不存在的教育、经历或荣誉；不会生成虚构身份。About 的展示名称、一句话介绍和中文介绍是核心信息，其余可稍后填写。多份已导入的结构化档案可通过档案选择框切换。

## 实际可填写字段

- **About**：中文与英文展示名、一句话身份、中文与英文介绍、关注领域、可选城市、头像、GitHub、公开联系邮箱、可增删的社交与其他链接。
- **Education**：可重复增加学校、学位、专业、起止时间、研究兴趣、课程、荣誉；可移动或移除行。
- **Experience**：可重复增加组织、岗位、日期、方式／地点、职责、核心贡献、可公开成果、工具。
- **Skills**：技能类别、名称、实际场景、相关项目、数字排序；没有虚构百分比。
- **Awards**：荣誉、组织、日期、个人／团队贡献、证明网址、证明图片。图片上传错误会显示在保存状态区域。
- **Projects**：保留名称、类别、封面／截图、技术栈、GitHub、Demo、顺序，增加中英文简介、解决问题、个人贡献、关键功能、成果、获奖、时间、项目进展。所有字段可编辑、保存、备份、公开后阅读与 Markdown 导出。
- **Photos**：保留导入、标题、说明、相册、标签、排序，增加图片时间、可选地点、相册封面、公开准备状态。地点默认仅本地；单独勾选才会进入公开包。
- **Notes**：保留 Markdown 导入、正文、分类、标签、创建／更新时间，增加可选封面、公开准备状态与已有排序。

“已准备好”仅是本地整理标记，不代表已经公开，更不能代替逐项审核。已发布状态来自网站的实际静态清单，而不是这个本地标记。

## 数据兼容与附件

个人档案保存为 `kind: resume` 的 Entry，可选字段 `structuredProfile` 包含 typed About / Education / Experience / Skills / Awards；头像和证明图片引用相同 Entry 的 `images` 数组。旧 `resume` 文本和 PDF 均保留。项目增加可选 `projectDetails`；旧项目没有该字段时继续按旧格式阅读，不改写原记录。

现有 v1 / v2 备份均可恢复；新备份继续使用向后可扩展的 v2，包括所有新增字段、原始附件与图片引用。恢复使用同一验证与合并事务，相同 ID 由备份版本替换，其他记录保留。浏览器、域名或端口变化时仍需手动导出／恢复。清除站点数据会删除未备份的草稿。

## 预览、审核与公开

1. 本地编辑后保存，使用“实时公开预览”查看中英文内容和实际头像／证明图片。
2. 打开审核面板，只选择确定可以公开的 Entry，并勾选审核确认。
3. 导出公开包，按照既有 `scripts/import_public_content.mjs` 处理，检查 `public/content` 差异，再提交、构建与部署。
4. 用无本地资料的浏览器核对公开版本。浏览器草稿永远不会自动上传。

公开照片地点在未单独同意时直接从公开数据中移除；公开导出和静态导入分别重新编码图片，移除 EXIF。静态导入使用 Sharp 处理，原始图片不可能仅因伪装的 MIME 或只改扩展名而跳过验证。GIF 公开版本为静态图。可读图片长边最多 2400px。保留原图的本地资料和完整备份仍可能包含 EXIF，必须按私人文件保管。完整备份不得提交到公开仓库。

仅当前头像、当前荣誉证明和当前随笔封面进入公开包，已移除或不再引用的旧图片被排除。发布包仍替换整套公开快照，未选择的旧内容会移除。项目全部当前截图是选中项目的一部分，应逐张审核。

## 集成契约

`ProfileCenter` 从 `src/ui/ProfileCenter.tsx` named export：

```tsx
<ProfileCenter
  entries={entries}
  published={published}
  onSave={saveEntries}
  onDirty={stableDirtyCallback}
  onRestore={restoreEntries} // 可选，缺省使用 onSave 合并
  onOpenLibrary={(kind, id) => openApp(kind, id)} // 可选
  onClose={closeCenter} // 可选
/>
```

`Library` 新增 `workspace?: boolean`、`onOpenWorkspace?: () => void`、`onOpenProfile?: () => void`。root 显式传 `workspace=false` 时强制只读公开视图；本地入口调用 root 的 workspace 状态切换。多窗口应使用稳定 onDirty 回调或对相同 dirty 值去重，汇总未保存提示。

## 已执行验证及边界

`tests/profile.test.ts` 覆盖部分草稿、必填缺失、重复行验证、双语和完整结构、旧 v1/v2 迁移、新字段全备份往返、头像／证明／封面原字节恢复、公开包排除未勾选地点、ready 不等于公开许可、未引用旧图片排除、真实 EXIF 文件重新编码后元数据移除、静态包实际落盘与校验、公开读取 API 还原。

测试夹具只写 `work/v3/`，明确标记为原创可丢弃测试资料，不是真实人物。本模块未改变正式 `public/content`，保留原有站点使用说明，没有加入真实个人资料或测试夹具。真实浏览器填写、上传、保存、刷新和迁移截图由本轮集成报告记录；单元测试与读取 API 测试不能替代该验收。
