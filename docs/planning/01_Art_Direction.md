# 01 · 视觉艺术指导

本页为 [E] 视觉规格提案，等待标准镜头验证与用户审美确认。研究依据与许可见 [03](03_Open_Source_Research.md)，镜头表见 [04](04_Scene_And_Camera_Plan.md)。

## 1. 视觉命题

一座有人生活、此刻安静的湖边木屋。访客先感知山谷、空气和水，再察觉窗内桌面，最后理解这是一个人的信息世界。视觉关键词：真实地理层次、温暖侧光、冷静湖水、克制生活痕迹。不是观光飞行游戏，也不以粒子、炫光、昼夜循环为主角。

摄影真实感分为五项，各项都必须成立：尺度可信、受光一致、材质可辨、接触自然、镜头有动机。禁止只用单张远景截图认定“照片级”；必须同时看 S01/S02、视角边界和运动中的画面。

## 2. 山谷、湖岸与建筑构图

- 采用不对称 U 形山谷。主峰在后景偏左，次峰较低；雪线在高海拔，避免“北欧”被误做成所有地面都积雪。山体仍是虚构场景，不声称复原某处实景。
- S01 中小屋在画面右侧约三分之一位置；左侧湖水形成负空间，斜向湖岸把视线引向门廊。山脊避免恰好穿过屋顶或窗框；天际线不居中切半。
- 近景 0–15m：两三组可辨识岸石、苔藓、落针与少量枝条；中景 15–150m：木屋、湖面、树丛；远景 150m–4km：林带、山体、空气。距离为制作分区，LOD 还要依据屏幕投影大小。
- 每层使用不同的轮廓尺度。近树有不规则枝梢；中景树群有疏密、年龄和高度变化；远林是连续林冠与空隙，不是一排等距三角形。
- 湖岸有浅水、浸湿石头、干湿过渡、根部和沉积；水与陆地边界不能是一圈白色描边。水体保持平缓内陆湖特征，不引入海浪泡沫。

## 3. 统一建筑与生活尺度

Three.js 世界单位 1 = 1m，Y 向上。以下是制作起点，不是测绘结果。

| 对象 | 基准规格 | 审美与工程约束 |
| --- | --- | --- |
| 小屋 | 外墙约 8.4×7.0m，檐高相对室内地面 2.7m，屋脊约 4.6m | 简单双坡屋顶、原木结构、克制深色屋面；内外门窗同一母版 |
| 原木 | 直径约 0.20–0.28m | 端部木纹、榫接和沉降缝有依据；不把每根原木都做成同一贴图圆柱 |
| 门 | 约 1.10×2.10m | 门槛真实厚度，镜头胶囊可通行；把手相对地面约 1m |
| 窗 | 湖面一侧约 2.4×1.5m | 木框、玻璃厚度可见；内外景空间连续 |
| 桌 / 椅 | 桌高 0.74m、桌面约 1.3×0.7m；座高 0.45m | 桌腿落地，椅背不挡关键电脑视线 |
| 电脑 | 约 0.32×0.22m，屏幕有效区约 0.30×0.188m | Mac 风格金属笔记本，独立原创外观细节，无 Apple 标志与系统贴图 |
| 人眼 | 站姿地面上 1.55–1.70m；近桌可降至坐姿 | 进入房间后不能仍像小型无人机贴天花板 |

屋内风格：北欧原木壳体、浅色织物、少量较深木家具、哑光金属。书、杯、线缆、照片框用于建立生活尺度；本轮不填真实照片、品牌界面或个人内容。避免把房间塞满无关物品。

## 4. 材质语言与细节优先级

| 材质 | 建议起点（待校准） | 必须看见的真实线索 | 常见失败 |
| --- | --- | --- | --- |
| 干原木 / 地板 | 非金属，roughness 约 0.45–0.80 | 木纹方向随构件，端纹独立，边缘轻微磨损 | 塑料高光、木纹尺寸巨大、每根复制 |
| 潮湿岩石 | 非金属，roughness 约 0.12–0.40；干区更粗糙 | 水线以下更暗，分区 roughness，几何破碎轮廓 | 全石镜面、只有 normal 无轮廓 |
| 苔藓 / 林地 | 非金属，多尺度颜色与法线 | 湿度、坡向、遮蔽决定分布 | 满地荧光绿、随机噪点密布 |
| 织物 | 高粗糙度，必要时有限 sheen | 织纹与褶皱尺度分开 | 大振幅 normal 像石头 |
| 金属电脑 | 金属度接近 1，roughness 从 0.25–0.45 校准 | 倒角反光、键缝、屏幕玻璃与铝壳可区分 | 没环境反射而发黑，Bloom 掩盖结构 |
| 玻璃 | 按性能档选择物理透射或简化反射 / 透明 | 斜视反射，窗框厚度，少量粗糙度 | 双层透明排序错误、窗外曝光不一致 |

上述 roughness 数字是不同材质的调试范围，不能代替同一光照下的材质校准。BaseColor 不含方向性太阳阴影；扫描资产先检查去光照结果。材质 close-up 优先使用 2K/4K 局部资源，而不是所有资产一律 8K。叶片 alpha-test 的闪烁、边缘和阴影必须看运动片段。

[F] Three.js Metallic-Roughness PBR 及环境映射接口见 [MeshStandardMaterial](https://threejs.org/docs/pages/MeshStandardMaterial.html)。PBR 提供物理一致性基础，不保证输入资产本身真实。

## 5. 午后光照与空气

- 固定一个午后太阳方案；初始太阳高度 25°–35°、偏暖直射约 4800–5500K、环境天光更冷。色温为艺术参考，最终以统一参考与灰卡校准，不把色温直接当作 Three.js 物理精度承诺。
- 从小屋西南侧斜照，给原木、屋檐和石头提供侧向体积。整个室外、室内、HDRI、反射、烘焙共享同一太阳方向。不要用多个任意方向的 DirectionalLight 把暗部填平。
- 室内靠湖侧窗形成柔和冷暖对比。间接光保留木材暖色反弹；窗外仍有可辨认湖岸，不允许全白洞口。门框暗部承担视觉揭示，而不是全屏黑场遮住所有错误。
- 大气透视主要来自距离与散射，远峰对比降低、偏冷，近景保持清楚。雾只连接层次，不掩盖不完整山体或水岸。
- 不默认制作真实体积云、实时全局光照、动态天气和昼夜循环。少量慢移云层或离线天空足够，加入前先检查地面与反射是否一致。

光照分工及避免双重能量的具体合同见 02 / 05。静态间接光对大幅开门、换家具、移动太阳不会物理更新；首版把可变化内容限定在小幅环境动态。

## 6. 摄影与色彩管理

- 画面以 16:10 的 1440×900 作为第一轮审美基准，同时检查 16:9 和窄屏。FOV 统一记为垂直 FOV，避免把 35mm 等效焦距和垂直角度混用。
- S01 垂直 FOV 40°–45°，S02 38°–42°，S03 45°–50°，S04 约 35°–40°。镜头不是靠突然改变 FOV 营造速度；路径以平移、看点与轻微转向建立空间。
- 启动后不持续自动摇镜头。可选微弱 idle 动态默认幅度极小，Reduced Motion 下关闭。无手持抖动、无滚转、无强制眩晕式推进。
- BaseColor / emissive 常规彩色贴图标注 sRGB；normal / roughness / metalness / AO 为非颜色数据；HDR 环境与 irradiance 按线性数据解释。工作空间 Linear-sRGB，显示输出 sRGB，只进行一次显示转换。
- Blender 与网页使用相同显示变换的对照版本（首选经验证的 AgX 配置；不匹配时提供统一 ACES 对照）。不能把 Blender 默认 AgX 成片与网页 ACES 输出直接当作同一色彩基线。引擎版本与后期顺序要锁定。
- 初始关闭 Bloom、颗粒、暗角、镜头污渍和强景深，先通过干净画面验收；再按意图少量添加。桌面文字不接受 3D Tone Mapping，不因曝光变化发灰。

[F] 色彩职责依据 [Three.js Color Management](https://threejs.org/manual/pages/color-management.html)。具体输出链和 DOM 匹配为项目 [E]，需浏览器截图校准。

## 7. 自然动态与声音

水面轻波、近叶小幅风动、偶发鸟声和连续但不抢注意力的环境底声。近景树干固定，叶尖 / 细枝按统一风场动；不同对象不应同相摆动。阴影预算不支持时减小摆幅，不让大片静态影子与摆动树冠分离。

环境声音在用户手势后启用；提供持续可见的静音按钮，记住选择。远湖、近窗、室内状态使用交叉淡入与低通变化；不强制自动音乐。无音频也应理解导航。

## 9. 人工审美验收

对 S01–S04 各做五项 1–5 分评分：构图与尺度、材质、光照、空间深度、运动连续性。静态镜头的运动项用相邻视角和片段补充。建议至少两位评审（用户 / 美术负责人 + 工程 / 三维负责人），单项均不低于 4，无一票否决缺陷。此为项目审美门槛，不是通用“照片级”客观测试。

一票否决：圆锥树占据可辨认近中景、屋体漂浮、湖岸白边、双重太阳、木纹错误尺度、窗口外景错位、镜头穿模、无预告的跳切、电脑文字明显模糊。曝光 / 材质错了先修输入，不用滤镜遮盖。

比较方式：同分辨率、同色彩设置、同镜头，浏览器原始截图 + 无 UI 运动片段 + 100% 局部裁切。不得通过后期修图、超采样离线帧或挑选唯一好角度来替代网页验收。
